# Alder Releases

Official public releases and downloads for **Alder — Mac Dictation**.

This repository contains distribution artifacts only. Alder's source code is
maintained separately in the private `yg1112/alder` repository.

## Downloads

- [Download the latest Alder DMG](https://github.com/yg1112/alder-releases/releases/latest/download/Alder.dmg)
- [View release history](https://github.com/yg1112/alder-releases/releases)
- [Sparkle update feed](https://alder.dzgapp.com/appcast.xml)
- [Alder website](https://alder.dzgapp.com)

## Publishing

Releases are generated by Alder's signed and notarized release pipeline. Do not
publish artifacts for other products in this repository.
